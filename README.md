# .github

Organization-wide defaults for [Natuleadan](https://github.com/natuleadan).

- `profile/README.md`: the public organization profile shown on the Natuleadan GitHub page.
- `profile/assets/banners/`: self-contained animated constellation and skills banners (no scripts, no text, no third-party services).
- `profile/assets/trademark/`: official brand logo and background vectors.
- `CODEOWNERS`: requires the code owner approval on all changes to `main`.
- `SECURITY.md`: default security policy inherited by repositories without their own.

## Brand

Colors `#b32323` and `#272727`; typeface Oxanium (used in headings on the website, not embedded here).

## Editing the profile

`main` is the sole permanent protected branch. Change `profile/README.md` or assets under `profile/assets/`, open a pull request from a short-lived topic branch into `main` (approved by the code owner per `CODEOWNERS`), and the profile updates after merge.
