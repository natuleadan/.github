# Security Policy

## Reporting a vulnerability

Please do **not** open a public issue for security problems.

Use GitHub's **Report a vulnerability** button on the affected repository (Security tab → Advisories → Report a vulnerability), or email contact@natuleadan.com with:

- A description of the issue and its impact.
- Steps to reproduce or a minimal proof of concept.
- The affected repository, version or commit.

We acknowledge reports within 5 business days and coordinate a fix and disclosure timeline with you.

## Supported versions

Only the latest released version of each repository receives security fixes.
